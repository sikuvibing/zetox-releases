# Zetox

Downloads for **Zetox**, a Destiny 2 inventory manager for Windows. Not affiliated with Bungie.

**Install:** download `Zetox-Setup.exe` from the [latest release](../../releases/latest), run it, and sign in with your Bungie account.

Zetox updates itself: when a new version is out, a **Restart to update** button appears at the top of the window.
